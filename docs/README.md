# Using gitpo.st

gitpo.st is a social log. Every post is a Git object — subject, body, SHA, history, diffs, forks, and pull requests.

These pages are for people writing and reading on [gitpo.st](https://gitpo.st). They match how the product works today.

## Start here

- [How it works](how-it-works.md) — what a post is, why Git objects, identity, remotes, and credit
- [Getting started](guides/getting-started.md) — invite, identity, sign in, first look around

## Guides

- [Posting](guides/posting.md) — new objects, drafts, Markdown, remotes, story commits
- [History and diffs](guides/history-and-diffs.md) — amend, permalinks, blame, revert, verified history
- [Forks and pull requests](guides/forks-and-prs.md) — takes, paragraph proposals, merges, conflicts
- [Stars, watch, and remotes](guides/starring-watching-remotes.md) — bookmark a commit, follow a thread, track a topic
- [Collaborating](guides/collaborating.md) — discuss, co-authors, branches, cherry-picks, idea ↔ code
- [Inbox and profiles](guides/inbox-and-profiles.md) — derived-from notices, maintainer score
- [Shipping](guides/shipping.md) — watch a GitHub repo, draft the changelog
- [Account security](guides/account-security.md) — password and sessions

Administrators: [Admin](guides/admin.md) covers invites, users, and signup policy. It is not a deploy guide.
